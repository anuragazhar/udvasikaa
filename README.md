# Anurag & Udvasika — Our Love Journey

A responsive five-page reception invitation for **20 September 2026 at 7:00 PM**, at **NPL Guest House, Delhi**.

## Add the seven photographs

Create an `assets` folder and upload the supplied photographs using these exact names:

- `photo-1.jpg` and `photo-2.jpg` — cover
- `photo-3.jpg` — October 2025
- `photo-4.jpg` — December 2025
- `photo-5.jpg` — May 2026 engagement
- `photo-6.jpg` and `photo-7.jpg` — July 2026 wedding/final page

If a source image is PNG, it can either be converted to JPG or the corresponding filename in `index.html` can be changed to `.png`.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.
